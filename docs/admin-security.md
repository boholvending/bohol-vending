# 后台安全码与留言备份

在服务器的交互式 SSH 终端执行：

```bash
cd /var/www/bohol-vending
node deploy/set-admin-password.mjs
```

安全码输入两次且终端不显示字符，长度为 8–12 位（建议使用随机字母、数字和符号组合）。脚本把加盐 PBKDF2 摘要和独立会话密钥写入当前运行账户的 `~/.config/bohol-vending/admin.env`，权限为 0600，并重启网站。以后改密码，重新运行同一命令；已有登录会话立即失效。此文件不能提交到 Git 或放进网站公开目录。部署流程会从此文件加载运行时配置。若文件不存在，后台无法登录。

若网页 SSH 终端不方便输入两次，可运行 `node deploy/set-admin-password.mjs --generate`。脚本会在该终端生成并显示一次 12 位随机初始安全码，绝不写入仓库或聊天。使用它登录后，进入后台“安全设置”修改为自己的 8–12 位安全码；修改会使旧登录会话失效。请勿把终端上显示的安全码截图或转发。

后台入口为 `/login`，管理员页面、内容编辑器和编辑接口需要有效登录；退出按钮会删除会话 Cookie。会话最长 8 小时。

留言保存于运行账户的 `~/.local/share/bohol-vending/inquiries.jsonl`。请定期把该文件备份到只有管理员能读取的位置；恢复时停止网站，将备份放回相同路径并保持目录 0700、文件 0600，然后启动网站。部署代码不会覆盖此文件。旧版未保存成功的留言无法恢复。

上线后验收：无登录访问 `/bohol-control-7e9c2f/inbox` 跳转 `/login`；`/api/inquiries` 的 GET 不返回客户资料；错误安全码不能进入；正确安全码能进入后台并查看既有留言；退出后再次访问后台需重新登录；前台询盘 POST 仍能保存。HTTPS、服务器防火墙、CloudPanel 和系统更新仍需按服务器运维要求维护。
